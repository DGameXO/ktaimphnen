# IMPHNEN Card Maker

Generator Kartu Anggota Resmi IMPHNEN (Ingin Menjadi Programmer Handal Namun Enggan Ngoding).

## Fitur
- Live preview tampak depan dan belakang kartu
- Ekspor resolusi tinggi ke format PNG dan PDF (rasio kartu standar ID-1/CR80)
- Tampilan responsif di desktop maupun perangkat mobile
- Aset logo tertanam langsung (Base64)
